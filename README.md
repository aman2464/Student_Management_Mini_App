##AppFeatures 
#Add Student Details: Admin can input student name, age, and course to maintain records.
#View Student List: Admin can view all registered students to track data effectively.
#Update/Delete Student List:Full CRUD functionality
#Validation:Server-side and Client-side data checks
#Bootstrap UI:Clean, responsive admin interface

###How to Run 
1.PrerequisitesEnsure MongoDB is installed and running on your local machine.
The default connection string used is mongodb://127.0.0.1:27017/studentDB.

2.Backend SetupBashcd backend node server.js 
The server runs on port 5000.

3. Frontend SetupBashcd frontend
npm start
The React application runs on port 3000.
